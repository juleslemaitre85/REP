# REP
Reproductibilty of experimentations

You can reproduce the experiences by running the following programms:
  - egal.c for the associativity experience, to see if (x+y)+z = x+(y+z)
  - banking.c for the banking problem
The results will be printed respectively in the answers_associativity.txt and answers_banking.txt files.
The previous results are already printed in those.

The factors that could have an effect on the computed answer are the programing language, the system running the program, and the program itself, how it was written.
